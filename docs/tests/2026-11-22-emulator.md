# Emulator test, 2026-11-22

A hands-on pass over phases P1–P12 and the user guide, done as a listener would, on the Android
emulator (Pixel-class phone, 1080 × 2424, 420 dpi, Android 16, API 37) with the Google Play debug
build (0.1.0 (1)), driven with `adb` (`uiautomator dump`, `input`). Media volume was 0 while
episodes played.

Sources:

| Source | What it is |
|---|---|
| **feeds** | Plain RSS feeds on the device (public shows, among them a Podcasting 2.0 feed with a chapters document and a feed with inline Podlove chapters) |
| **local feed** | A feed served from the test machine, to which episodes were added during the test (download rules, playing on) |
| **canary** | own.audio at `api-canary.own.audio` (1.0.7, 1.0.8 during the test), a member account of a test family |
| **old own.audio** | An own.audio server still on 1.0.0-beta (v2 revision 0), also used through its gPodder API |
| **ABS** | An Audiobookshelf test server (2.37.1) with three podcast libraries, an account without upload permission |
| **podfetch** | A podfetch gPodder sync server |
| **Apple** | Apple's podcast charts and search (Discover without an own.audio catalogue) |
| **demo** | The public demo library (Try the Demo Library) |

The emulator's clock ran five minutes behind real time; own.audio keeps the position with the
newer `at`, so a few position checks were judged with that in mind.
